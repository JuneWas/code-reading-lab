# 要件

## プロジェクトの目的

実務で Java、JavaScript、Spring Boot、Vue.js を利用する Web システムを、自力で読解・修正・実装できるエンジニアを育成する。

## 想定ユーザー

Java または JavaScript の基本文法を学び、実務コードの処理を追ったり、既存のコードを修正したりする練習をしたい初学者・若手エンジニアを想定する。

## MVP 機能要件

| 機能 | 状態 |
| --- | --- |
| Java と JavaScript の学習問題一覧 | 実装済み。言語別に絞り込み、問題詳細を開ける。 |
| シンタックスハイライト付きコード表示 | 実装済み。Java と JavaScript のコードをダークテーマで表示する。 |
| コードリーディング問題と処理結果の予測 | 実装済み。問題文を読み、選択肢を一つ選んで回答する。 |
| 回答の正誤判定と解説表示 | 実装済み。回答送信後に正誤・正解・解説を表示する。 |
| 既存コードを修正するコードライティング問題 | 予定・未実装 |
| 学習進捗のブラウザ内保存 | 予定・未実装 |

MVP の対象外は、ユーザー認証、データベース、AI API 連携、Java コードのサーバー実行とする。

## 学習問題のデータ要件

Phase 1 Step 2 で、この要件に従って Java と JavaScript の読解問題を各 1 問、静的データとして実装した。一覧と読解演習はこのデータを使用する。ライティング問題は未実装。

| 項目 | 型・許容値 | 必須条件・制約 |
| --- | --- | --- |
| 問題 ID `id` | 空でない文字列 | 共通で必須。全問題で一意とし、公開後はタイトルや出題順が変わっても維持する。 |
| 言語 `language` | `java` または `javascript` | 共通で必須。 |
| カテゴリー `category` | 空でない文字列 | 共通で必須。主な学習テーマを一つ指定する。同じテーマには同じ表記を使う。 |
| 難易度 `difficulty` | `beginner`、`intermediate`、`advanced` | 共通で必須。表示名はそれぞれ「初級」「中級」「上級」。 |
| 問題タイプ `type` | `reading` または `writing` | 共通で必須。タイプによって回答用の項目が変わる。 |
| 問題タイトル `title` | 空でない文字列 | 共通で必須。 |
| ソースコード `files` | `{ path: string, content: string }` の配列 | 共通で必須。MVP は 1 件。ファイル名または問題内の相対パスを `path`、空でないソース本文を `content` に格納する。パスは問題内で一意とする。ライティングでは修正前のコードを格納する。 |
| 問題文 `prompt` | 空でない文字列 | 共通で必須。ライティングでは達成すべき条件も記載する。 |
| 選択肢 `choices` | `{ id: string, label: string }` の配列 | `reading` のみ必須。2 件以上とし、空でない ID と表示文を持たせる。ID は問題内で一意とし、表示文や並び順の変更後も維持する。`writing` では省略する。 |
| 正解 `correctChoiceId` | 文字列 | `reading` のみ必須。該当問題の選択肢 ID のうち 1 件を指定する。`writing` では省略し、判定に必要な専用項目は Phase 3 で定義する。 |
| 解説 `explanation` | 空でない文字列 | 共通で必須。解答後に、正解や修正方法の根拠を示す。 |

複数ファイル問題は将来の拡張とする。対応時は同じ `files` に複数件を格納し、既存の単一ファイル問題は同じ形式で扱う。設計例は [アーキテクチャ](architecture.md#読解問題のサンプル) に記載する。

## 開発ロードマップ

1. Phase 0（実装済み） — Vue アプリの初期画面、ビルド、開発を再開するためのドキュメントを整備する。
2. Phase 1（実装済み） — 問題データを設計・実装し、言語別の問題一覧から詳細に移動できるようにした。
3. Phase 2（実装済み） — 問題一覧と同じ変更で、コード表示・回答・判定・解説まで通して操作できる読解演習を実装した。
4. Phase 3（予定） — 既存コードを修正するライティング問題を追加する。
5. Phase 4（予定） — 学習進捗をブラウザ内に保存し、再読み込み後に復元する。

## 読解演習の操作

PC・スマートフォンで一覧と演習を操作できる。一覧へ戻ると言語フィルターを維持し、別の問題を開くと回答状態をリセットする。問題のソースコードは表示用データとして扱う。

## 完了条件

- Phase 0 はトップ画面で「Code Reading Lab」が表示され、`npm run build` が成功し、必要な Markdown が揃っていること。進捗に検証結果と次の一作業を記録し、変更内容と検証結果を報告する。
- MVP は Java と JavaScript の問題を一覧から開けること。ハイライト付きコードを読み、リーディング問題の回答結果と解説を確認できること。ライティング問題で既存コードを修正でき、再読み込み後も学習進捗を確認できること。
